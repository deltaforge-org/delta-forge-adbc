DeltaForge ADBC Driver 1.0.5.

DeltaForge ADBC driver: Arrow-native read and write for Delta Lake and
Apache Iceberg. Bundled Power Query connector for Power BI Desktop, 13.7x
faster than .NET ODBC on a 1M-row scan.

Includes: driver shared library (Linux .so, macOS .dylib, Windows .dll),
platform installers (.deb, .pkg, .msi), and the DeltaForgeAdbc.mez
Power BI custom connector.

The ADBC driver is the Arrow Database Connectivity binding for the
DeltaForge engine. It carries Arrow record batches end-to-end (no
per-row marshalling) and is the preferred connector for wide-column
scans from Power BI, Apache Arrow ADBC clients, and any application
linked against libadbc_driver_*.

See SETUP_NOTES.md in the Windows MSI / PowerBI-ReadMe.txt next to
each .mez for registration steps.

More at https://deltaforge.org/pages/adbc.html
